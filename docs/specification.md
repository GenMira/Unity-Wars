# 概要
第二次世界大戦をモデルとした2D戦略ゲーム。マスで区切られた盤面上を自身のユニットを動かして、重要都市マスを占領し、最終的に相手の基地を占領することで勝利となる。1vs1、想定対戦時間は30分。同一端末で交互に操作するローカル対戦である。。

# ゲームループについて
陣営は赤陣営と青陣営に分かれる。まず赤陣営が動く。
各陣営は基地を1つ所有して開始する。初期所有施設、初期ユニット、初期資金は対戦用マップ設定で指定する。
プレイヤーは自分のターンに次の行動をすることが出来る。自分のターン内であれば何度でも行動することが出来る。

- ユニットを行動させる
- ユニットを製造する

ユニットの生産には資金が必要となる
資金は自分のターン開始時に手に入る。基本資金として毎ターン500の収入がある。
占領している市街地が多いほど毎ターンの金銭収入が多くなる。
各ユニットは1ターンに行動することが出来る。行動は移動と活動からなる。移動を確定させたのち活動をする。

移動
- ユニットを移動させる

活動
- 敵ユニットに攻撃する
- ユニットで中立/敵の施設を攻撃/占領する
- ユニットを他のユニットに搭載させる

ターン終了を選択することでターンが終わり、相手にターンが渡る。
全盤面、双方のユニット、施設所有者・耐久度・資金は常に公開する。


# マスについて
マップは6角形のマスが敷き詰められて構成されており、マップはいくつかの種類を用意する。盤面外への移動や盤面端の折り返しは認めない。
六角形の辺が隣接するマスへの移動を1マス移動とする。

# 戦闘について
活動で敵ユニットへの攻撃を選択し、攻撃の種類を選択すると戦闘が発生する。
戦闘では攻撃を仕掛けたユニット、攻撃されたユニットの双方が相手にダメージを与える。
与えるダメージ量は(攻撃力-敵ユニットの防御)である。
防御貫通と記された攻撃、反撃の場合は攻撃力がダメージ量となる
遠隔攻撃と記された攻撃を受けた側は、反撃をすることはできない。
反撃：なしと記された攻撃はその武器を反撃に使用できない
攻撃を受ける側は、攻撃側の兵科別に反撃で記された攻撃で反撃する。
体力が0になったらユニットは消滅する。

## 3. ターンと行動の状態（補完案）

### ターン開始・終了

1. 対戦開始時は赤のターンを開始する。
2. ターン開始時、その陣営が現在所有する市街地数 × 1000の資金を一度だけ加算する。赤・青とも初回ターンから適用する。初期資金はこの収入とは別に設定する。
3. その陣営の盤面上のユニットを未行動に戻す。敵ユニットの行動状態は変更しない。
4. 手番プレイヤーは、未行動ユニットの行動と生産を任意の順序で実行できる。生産回数は資金と生産場所の空きによって制限される。
5. プレイヤーが「ターン終了」を選ぶと未行動ユニットも行動機会を失い、相手のターンを開始する。全ユニットが行動済みでも生産可能なので、自動終了はしない。

赤・青それぞれの手番を1ターンと呼ぶ。自軍ターンの途中で占領した市街地から収入を受け取るのは、次の自軍ターン開始時とする。施設取得による臨時収入はない。

### ユニットの行動

- 1ユニットにつき、自軍の1ターンで「移動を最大1回、その後に活動を最大1回」実行できる。
- 移動しないことを選択できる。移動距離0の状態から攻撃・占領・搭載・降車・待機を選べる。
- 活動は、攻撃・占領・搭載・降車・待機のうち1つとする。武器が複数あっても攻撃回数は1回。
- 移動確定後は元の位置に戻せない。活動後は行動済みとなり、追加移動や追加活動はできない。
- 移動確定後に活動選択を保留し、別ユニットを操作することは可能。そのユニットは移動済み・活動未実行の状態を保持する。
- 自軍ターン中にユニットを未行動へ戻す効果は設けない。反撃の処理は自軍ターンの行動とは別扱いとする。
- 不正な操作や対象のない操作では、行動状態・資金・体力・位置を変更しない。

## 4. マス、移動、射程（補完案）

- 1マスは地形を必ず1つ持ち、施設を最大1つ持つ。施設は地形に重なる情報として扱う。
- 初期版の基地・工業地帯・市街地は平野上にのみ配置する。施設マスへの侵入可否も地形の条件に従う。
- 盤面上の1マスには、所属陣営にかかわらずユニットを最大1体だけ配置する。搭載中のユニットは盤面上の配置数に含めない。
- 移動は上下左右への経路で行い、1マス進むごとに移動力を1消費する。地形別の追加移動コストは初期版では設けない。
- 侵入不可地形、味方または敵のユニットがいるマスを通過できない。移動先にも指定できない。搭載は隣接位置から行う別の活動とする。
- 到達可能範囲は実際に通行可能な経路の長さで判定する。直線距離だけでは判定しない。
- 攻撃距離は「横方向のマス差の絶対値 ＋ 縦方向のマス差の絶対値」とする。射程Nは距離1以上N以下を意味する。
- 攻撃の射線は地形・施設・途中のユニットで遮られない。範囲攻撃はなく、選択した敵1体だけを対象とする。
- 敵ユニットが隣接していても、移動制限や移動に対する迎撃は発生しない。
- 地形・施設による防御補正、補給、修理、継続ダメージは初期版では設けない。

## 5. 戦闘と反撃（補完案）

### 攻撃条件とダメージ

- 未活動の自軍ユニットが、射程内の盤面上の敵ユニットに対して武器を1つ選択して攻撃する。味方・自分自身・搭載中のユニットには攻撃できない。
- 「反撃：通常兵科」等は、その武器を反撃に使用できる相手兵科の指定と解釈する。能動的な攻撃の対象兵科を制限する記述とは扱わない。
- 初期版の地上ユニット同士では全武器を能動的な攻撃に使用できる。「対空攻撃」は航空機実装時の対象判定用とし、初期版では追加効果を持たない。
- 通常ダメージは `max(0, 攻撃力 - 対象の防御)` とする。負のダメージによる回復は発生しない。
- 防御貫通武器の攻撃およびその武器による反撃は、攻撃力をそのままダメージ量とする。反撃全般が防御貫通になるわけではない。
- 命中は確定とし、乱数・クリティカル・残存体力による攻撃力低下は設けない。体力は整数で管理し、被ダメージ後は0未満にしない。

### 反撃条件

- 攻撃を受けたユニットが、攻撃側の兵科に対応する反撃武器を持ち、その武器の射程内に攻撃側がいる場合に、1回だけ反撃する。
- 歩兵の通常攻撃には反撃指定がないため、補完案では通常兵科・機械兵科への反撃に使用可能とする。これは追加定義として確定が必要。
- 反撃対象の指定がない他の武器、および「反撃：なし」の武器は反撃に使用できない。「支援砲撃で攻撃された相手が反撃できない」という意味にはしない。
- 条件を満たす反撃武器が複数ある場合は、攻撃側に与えるダメージが最大の武器を自動選択する。同値の場合は仕様書の掲載順を優先する。
- 行動済み・生産直後・降車直後でも反撃可能。相手ターン中の反撃回数に上限は設けず、反撃は行動状態を消費しない。
- 反撃に対してさらに反撃はしない。施設への占領活動では反撃は発生しない。

### 戦闘処理の順序

1. 攻撃の成立条件を確認し、双方の戦闘前の状態から攻撃・反撃のダメージを計算する。
2. 本文の「双方がダメージを与える」に合わせ、両方のダメージを同時に適用する。反撃条件を満たしていれば、防御側がこの戦闘で撃破される場合も反撃する。
3. 体力0になったユニットを除去する。双方が同時に撃破される場合もある。搭載ユニットの扱いは8に従う。
4. 生存した攻撃側を行動済みにする。結果を表示した後、次の操作を受け付ける。

## 6. 施設の攻撃・占領（補完案）

- 施設の状態は、種類、所有陣営（赤・青・中立）、最大耐久度、現在耐久度で管理する。所有者を未設定にする場合は中立と同義とする。
- 対戦開始時の施設耐久度は各施設の最大値とする。施設を所有していることと、その上にユニットがいることは独立している。
- 初期版の全陸上ユニットは、乗っている中立・敵施設に対して占領活動を実行できる。施設の隣のマスからは実行できない。
- 施設への「攻撃」と「占領」は初期版では同じ活動とし、施設攻撃力の分だけ耐久度を減らす。防御値や戦闘武器は使用しない。
- 耐久度が残っている間は所有陣営を変更しない。施設上に敵ユニットがいるだけでは所有者は変わらない。
- 耐久度が0以下になる活動を解決した時点で、活動したユニットの陣営へ所有権を移す。耐久度は直ちに最大値へ戻す。余剰の施設ダメージは持ち越さない。
- 部分的に減った施設耐久度は、占領ユニットが離れる・撃破される・ターンが変わる場合も残る。自然回復はしない。
- 中立施設の減少済み耐久度は共通の状態とし、最後に耐久度を0にした陣営が取得する。陣営別の占領進捗は設けない。
- 自軍施設には占領活動を実行できない。自軍ユニットを置いても耐久度は回復しない。
- 施設上に敵ユニットがいる場合は、まずその敵をユニットへの攻撃で排除し、後の行動機会に施設上へ移動して占領する。ユニットへの攻撃と施設占領を1回の活動で同時実行しない。
- 基地占領時は9の勝利判定を直ちに行う。基地以外の施設は占領しても盤面から除去しない。

## 7. 資金と生産（補完案）

- 資金は陣営ごとに独立して管理する非負の整数とし、借金やユニット売却は設けない。
- 自軍ターン中、自軍所有の工業地帯のマスが空いていて、価格以上の資金がある場合に生産できる。
- 生産ユニットは選択した工業地帯のマス上に出現する。隣接マスへの生産や自動配置はしない。
- 生産を確定する時点で所有権・マスの空き・資金を再確認し、価格の減算とユニットの配置を一括して行う。失敗時はどちらも変更しない。
- 生産ユニットは最大体力で出現し、そのターンは行動済みとする。初めて行動できるのは次の自軍ターンから。
- 同じ工業地帯の生産回数に追加の上限は設けない。ただし生産したユニットがそのマスを占有し、そのターンに動けないため、通常は1ターンに1体となる。
- このターンに占領した工業地帯も生産の対象にできるが、占領ユニットがマスを占有している間は生産できない。
- 基地と市街地では生産できない。維持費、生産待ち時間、生産予約、ユニット総数の上限は初期版では設けない。

## 8. 搭載・降車（補完案）

- 初期版では装甲車1体につき、味方の通常兵科ユニットを最大1体搭載できる。容量は未定義だったため、これは追加の提案値であり確定が必要。
- 搭載は搭載されるユニットの活動として行う。移動確定後の位置で、上下左右に隣接する空き容量のある味方装甲車を選択する。
- 搭載されたユニットは盤面から取り除き、装甲車に関連付けて保持する。体力は変わらず、そのターンの行動を終了する。
- 搭載活動は装甲車自身の行動状態を消費しない。装甲車が行動済みでも搭載でき、未行動なら搭載後に通常どおり行動できる。
- 搭載中のユニットは移動・攻撃・占領・反撃ができず、敵からの直接攻撃対象にもならない。入れ子の搭載や輸送車両間での直接移乗はできない。
- 搭載中も装甲車の移動力・攻撃力は変化せず、通常どおり移動・攻撃・占領できる。
- 降車は装甲車の活動として行う。移動後または移動を省略した状態で、装甲車に上下左右で隣接する空きマスのうち、搭載ユニットが侵入可能な地形を選択する。
- 降車したユニットはそのターンの行動済みとして配置する。装甲車も行動済みとなり、その活動で攻撃・占領はできない。
- 有効な降車先がない場合は降車できず、搭載状態と行動状態を維持する。
- 装甲車が撃破された場合、搭載ユニットも同時に消滅する。自動脱出や撃破位置への配置は行わない。
- 将来の輸送艦・航空輸送ユニットでは、容量、積載対象、接岸・離着陸、降車先の条件を別途確定する。

## 9. 勝敗と対戦終了（補完案）

- 敵基地の占領が成立した直後に、占領した陣営の勝利とする。以後の行動・生産・収入処理は実行しない。
- 全ユニットを失っても、敵基地が占領されていなければ敗北にはしない。工業地帯で再生産できる場合があるため。
- 工業地帯や市街地をすべて失った場合も、自動敗北にはしない。
- プレイヤーは自軍ターン中に投了できる。確認後、相手の勝利として終了する。
- 基地占領も投了も起きない場合、対戦は継続する。膠着による自動引き分けは初期版では設けないため、長期化は起こり得る。引き分け合意・手数制限が必要なら別途定義する。
- 対戦終了時は勝者と終了理由を表示し、盤面の確認、再戦、開始画面へ戻る操作を提供する。再戦では初期配置・初期資金から開始する。

## 10. 操作と表示の最低要件（補完案）

- 現在の手番、双方の資金、施設所有者、ユニットの体力と行動状態を確認できること。
- ユニット選択時は兵科、移動力、武器と射程、攻撃力、防御、施設攻撃力、搭載内容を確認できること。
- 未行動ユニットの選択で移動可能マスを表示する。移動しない選択肢も提供する。
- 移動先・活動・武器・対象を選択中は、確定前なら取消できる。確定済みの移動・活動・生産は取り消せない。
- 攻撃確定前に、使用武器、与ダメージ、反撃の有無と被ダメージを表示する。反撃は実際の射程・兵科条件から算出する。
- 占領前に現在耐久度と活動後の耐久度、所有権が変わるかを表示する。敵基地を占領する場合は勝利になることを表示する。
- 生産画面では費用と生産可否を表示する。実行不可の場合は資金不足・他陣営の施設・マス占有などの理由を示す。
- 選択可能な活動がない場合も待機で行動を終了できる。移動しない待機も可能。
- ターン終了時に活動未実行のユニットがいる場合は、その行動機会が失われる旨を確認する。投了にも確認を設ける。
- 行動処理・演出中は重複入力を受け付けない。盤面クリックや選択解除だけでは行動を消費しない。
- セーブ・ロード、途中再開、リプレイは初期版の対象外という案とする。採用する場合は保存範囲と再開位置の追加定義が必要。

## 11. 作者による確定が必要な項目

補完案で挙動を提案した項目と、具体的な内容が未作成の項目を区別する。以下の決定はユニットの数値バランスの評価とは別に必要となる。

| 項目 | 提案または必要な決定 |
| --- | --- |
| 初期版の対戦形式 | ローカル交互対戦の案を採用するか。オンラインなら同期・切断・復帰・不正操作検証の仕様、AIなら行動方針の仕様を追加する |
| 戦闘ルール | 同時ダメージ、反撃にも射程を適用すること、「反撃：なし」の解釈、歩兵の反撃対象、武器の能動攻撃対象を確定する |
| 占領ルール | 取得直後の耐久度全回復、部分耐久度の維持、中立施設の進捗共有を確定する |
| 行動と輸送 | 移動確定後の取消不可、装甲車の容量1、降車後の行動不可、車両撃破時の搭載ユニット消滅を確定する |
| 対戦用マップ | 縦横サイズ、全マスの地形、基地・工業地帯・市街地の位置と初期所有者、初期ユニットの種類と位置を具体的に指定する |
| 初期資金 | マップ設定に具体的な初期資金を指定する。適正額の評価はテストプレイで行う |
| マップの成立条件 | 基地は各陣営1つ、侵入不可地形や同一マスへの初期配置なし、陸上の経路で双方の基地に到達できること。初期ユニットがない陣営は、開始時に空きの工業地帯を持ち、初回収入込みの資金で少なくとも1体生産できること |
| 基本操作 | 使用端末・入力方法、盤面が画面に収まらない場合のスクロール・拡大縮小を決める |
| 保存と中断 | 初期版で途中保存を必要とするか決める。保存するなら、手番・資金・ユニット状態・搭載関係・施設状態・初期マップ識別子を保持する |
| 将来の海空要素 | 「航空機」の「輸送艦」が航空輸送機を指すか確認する。攻撃対象兵科、地上・海上・航空の重なり、搭載容量、軍港・空港の機能を拡張時に定義する |

## 12. 実装時の受け入れ確認項目

以下は、補完案を採用した場合に満たすべき挙動の確認項目。今回は仕様レビューのみであり、テストやコード実装は行っていない。

- 赤から開始し、手番を交代するたびに対象陣営だけに収入が一度入り、対象陣営だけの行動状態が更新される。
- 移動確定後に再移動できず、活動確定後に再活動できない。移動せずに攻撃や待機できる。
- 移動範囲内でも侵入不可地形やユニットで経路が塞がれているマスへ移動できない。盤面外や斜めへ直接移動できない。
- 防御が攻撃力以上でも回復しない。防御貫通が反撃にも適用され、通常の反撃では防御を差し引く。
- 射程外では反撃せず、射程内で条件を満たせば行動済みでも反撃する。撃破される防御側も同時ダメージの条件で反撃し、相打ちを処理できる。
- 複数の武器を持っても活動1回で攻撃は1回。「反撃：なし」の武器を能動的に使っても、相手の反撃条件は通常どおり判定される。
- 占領途中で離脱しても耐久度が残り、取得した時だけ所有者が変更されて耐久度が最大に戻る。市街地の収入は次の自軍ターンから増える。
- 資金が価格と同額なら生産でき、価格未満や生産マス占有時は、資金も盤面も変化しない。生産直後は移動・活動できない。
- 搭載は乗る側の活動を消費する。容量超過や不適切な兵科を搭載できず、降車先がない場合は状態を変更しない。
- 降車ユニットはそのターン行動できず、輸送車両撃破時には搭載ユニットも除去される。
- 基地占領直後に勝利画面となり、二重入力や続くターン開始で対戦状態が変わらない。
- 不正な初期マップ設定を対戦開始前に検出し、問題のマスや未設定項目を特定できる。
