# 概要
第二次世界大戦をモデルとした2D戦略ゲーム。マスで区切られた盤面上を自身のユニットを動かして、重要都市マスを占領し、最終的に相手の基地を破壊することで勝利となる。1vs1、想定対戦時間は30分。

# ゲームループについて
陣営は赤陣営と青陣営に分かれる。まず赤陣営が動く。
プレイヤーは自分のターンに次の行動をすることが出来る。自分のターン内であれば何度でも行動することが出来る。

- ユニットを行動させる
- ユニットを製造する

ユニットの生産には資金が必要となる
占領している市街地が多いほど毎ターンの金銭収入が多くなる
各ユニットは1ターンに行動することが出来る。行動は移動と活動からなる。移動を確定させたのち活動をする。

移動
- ユニットを移動させる

活動
- 敵ユニットに攻撃する
- ユニットで中立/敵の施設を攻撃/占領する
- ユニットを他のユニットに搭載させる

# 戦闘について
活動で敵ユニットへの攻撃を選択し、攻撃の種類を選択すると戦闘が発生する。
戦闘では攻撃を仕掛けたユニット、攻撃されたユニットの双方が相手にダメージを与える。
与えるダメージ量は(攻撃力-敵ユニットの防御)である。
防御貫通と記された攻撃、反撃の場合は攻撃力がダメージ量となる
攻撃を受ける側は、攻撃側の兵科別に反撃で記された攻撃で反撃する。
体力が0になったらユニットは消滅する。
